# EmployeeAudit

Плагин [Vencord](https://github.com/Vendicated/Vencord) для фракции «Больница»
на GTA 5 RP проекте **Russia Online**.

По клику в контекстном меню сообщения-отчёта на повышение собирает готовый текст
кадрового аудита и кладёт его в буфер обмена (или сразу в поле ввода).

## Что делает

Правый клик по сообщению-отчёту → **«Скопировать кадровый аудит»** →

```
Повышение
Повышает: <@178560714821206016> Виктор Громов | 500
Повышен(а): <@100000000000000001> Артур Белов | 10001
Прежний ранг: 5
Новый ранг: 6
Причина повышения: https://discord.com/channels/…/…/…
```

Пункт меню появляется только на сообщениях с embed'ом «Отчет на повышение»
и только в канале отчётов (канал настраивается).
Ранги сверяются с таблицей СМП: опечатка в форме или повышение через ранг дают
предупреждение (копированию не мешают).

## Установка

Плагин из `userplugins` работает только в Vencord, собранном из исходников:

```bash
git clone https://github.com/Vendicated/Vencord
cd Vencord && pnpm i

git clone https://github.com/JellyColonel/EmployeeAudit src/userplugins/EmployeeAudit
# либо симлинк на уже склонированный репозиторий:
# ln -s ~/projects/VencordPlugins/EmployeeAudit src/userplugins/EmployeeAudit

pnpm build && pnpm inject
```

Затем включить плагин в настройках Vencord и заполнить в них своё имя, статик и
Discord ID (ID можно оставить пустым — подставится текущий аккаунт).

Для разработки: `pnpm watch`, перезагрузка Discord по Ctrl+R.

## Настройки

| Настройка | Назначение |
|---|---|
| Имя и фамилия, статик, Discord ID | строка «Повышает» |
| Каналы | ID каналов через запятую, где показывать пункт меню. Пусто — во всех |
| Что делать по клику | копировать / вставить в поле ввода / и то и другое |
| Шаблон аудита | текст с плейсхолдерами `{targetName}`, `{oldRank}`, `{reportLink}` и др. |
