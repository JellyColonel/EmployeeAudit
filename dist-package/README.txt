EmployeeAudit — плагин Vencord для кадрового аудита
==================================================

Что это
-------
Плагин читает сообщение-отчёт на повышение и по клику собирает готовый текст
кадрового аудита, копируя его в буфер обмена.

Правый клик по отчёту -> «Скопировать кадровый аудит» -> текст в буфере.

Что нужно заранее
-----------------
Windows и установленный Vencord. Если Vencord ещё нет, поставьте его
официальным установщиком с https://vencord.dev и только потом ставьте плагин.

Установка
---------
1. Закройте Discord полностью: значок в трее -> Quit. Не просто крестиком.
2. Двойной клик по install.bat.
3. Запустите Discord.
4. Настройки -> Vencord -> Plugins -> включите EmployeeAudit.
5. Откройте настройки плагина и впишите своё имя и Static ID.
   Без них аудит не соберётся — плагин об этом скажет.

Язык интерфейса подстраивается под язык Discord. Его можно переключить
вручную в настройках плагина: Auto / English / Русский.

Обновление
----------
Двойной клик по update.bat — он скачает последнюю версию сам.

Что важно знать
---------------
Эта сборка заменяет файлы Vencord своими, поэтому встроенный апдейтер Vencord
в ней отключён: вкладки Updater в настройках не будет, уведомлений об
обновлениях тоже. Обновляйтесь через update.bat.

Если запустить официальный установщик Vencord заново, он вернёт свою сборку и
плагин пропадёт. Тогда просто запустите install.bat ещё раз.

install.bat всегда делает резервную копию прежней сборки рядом, в папке
%APPDATA%\Vencord, с именем вида dist.bak-20260901-120000.
